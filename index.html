La connexion au capteur a échoué. Vérifiez dans l'ordre :
  1. Le H10 est porté, électrodes humidifiées (sinon il peut se mettre en veille).
  2. Aucune autre application n'est connectée à la ceinture : Polar Beat / Flow, montre, téléphone, autre onglet. Désactivez le Bluetooth de ces appareils.
  3. Retirez le H10 des appareils Bluetooth associés du système (Windows : Paramètres > Bluetooth ; Android : Bluetooth > oublier), puis réessayez.
  4. Rechargez la page, relancez la connexion. Un redémarrage du Bluetooth de l'ordinateur règle souvent le problème.
Le message d'erreur dans la barre d'état indique l'étape qui a échoué.
